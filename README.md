## Overview
This repository contains a curated collection of my machine learning engineering and AI research projects. My work primarily focuses on large language models, cognitive modeling, and efficient model fine-tuning architectures.

## 📁 Project Directory

### 1. [Large Language Models & NLP](./LLMs_and_Transformers)
*Core NLP architecture builds and text classification.*
* **[Practice TinyGPT](./LLMs_and_Transformers/PracticeTinyGPT.ipynb):** Implementation and exploration of a scaled-down GPT architecture.
* **[Transformer Build](./LLMs_and_Transformers/Transformer_Build.ipynb):** Step-by-step construction of a Transformer model from scratch.
* **[Spam or Ham Classifier](./LLMs_and_Transformers/Spam_or_Ham.ipynb):** NLP classification model for text filtering.

### 2. [Computer Vision](./Computer_Vision)
*Applied computer vision and deep learning.*
* **[Tennis Player Action Recognition](./Computer_Vision/Tennis_Player_Action_Project.ipynb):** PyTorch-based image classification model to identify specific actions and stances of tennis players from raw visual data.
